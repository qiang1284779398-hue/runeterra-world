# 符文之地 · 本机世界模拟器

基于《英雄联盟》符文之地官方世界观的个人世界模拟项目。目标是在 Android 手机上运行一个持续演化的沙盒世界，并记录居民从出生到死亡的完整人生。

## 项目原则

- **尊重官方设定**：地区、种族、历史背景和已知规则以 Riot Games 官方公开设定为基础。
- **原创模拟内容明确标识**：新增居民、家庭、事件、政治变化和模拟历史均为本项目生成，不代表 Riot 官方正史。
- **世界不围绕主角运行**：居民有独立目标、关系、职业、资源和生命周期；观察对象不会获得剧情保护。
- **可追溯**：世界时间、居民状态、事件日志和人生记录持久化保存。
- **本机优先**：模拟由 Android 设备本地执行，不依赖云端 GPU 或在线生成服务。

## 当前开发阶段

项目刚初始化。按以下顺序推进：

1. Android 原生应用骨架与可重复构建。
2. 本机世界时钟、存档和前台服务。
3. 地区、居民、家庭、职业、资源与基础经济模拟。
4. 人口迁徙、政治组织、外交、冲突、魔法与战斗系统。
5. 居民长期记忆、因果事件链和完整人生档案。
6. 选择一名普通居民，旁观其完整一生并生成传记。

## 本机运行说明

目标是在用户主动开启“世界运行”后，通过 Android 前台服务继续模拟，并显示常驻通知。系统强制停止应用、关机或厂商后台限制仍可能中断运行；应用必须在恢复后从本机存档继续。

## 技术路线

- Kotlin / Android 原生
- Gradle Kotlin DSL
- Android Foreground Service
- 本机持久化存档（后续接入 Room）
- GitHub Actions 自动构建 Debug APK
